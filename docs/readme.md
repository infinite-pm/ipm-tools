### The `gl:` link convention

Dev docs and generated fixture pages use `gl:` source links —
`gl:pkg/layout7/route.go`, `gl:docs/ipmt-spec.md#L605-L608`. Read them as
paths from the repo root with an optional `#L<from>[-L<to>]` line range.
They are produced and consumed by our tooling; GitHub renders them as plain
text, so follow the path by hand there (the plain markdown link next to a
`gl:` link, where present, is the clickable fallback).
